This app is a private tool used only by the owner of the YouTube channel. It reads the channel’s own analytics and public data about selected YouTube channels through Google’s APIs. The data is used only to create a weekly summary report, which is sent to the owner’s own Discord or Telegram account and stored in a private history file. The app does not sell, share, or transfer data to any third party, except that Google’s Gemini service processes the text to write the report. Data can be deleted at any time by deleting the repository and history file, and by revoking the app’s access at myaccount.google.com/permissions.
